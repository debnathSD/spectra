# Changelog

## 0.1.0

First release.

- **Spectra: Profile page load** records the page several times with your project's Spectra and shows the medians.
- Findings in the **Problems panel**, at the file and line responsible, with the suggested fix.
- **CodeLens** above components (renders, render time, wasted renders) and hot functions (own time).
- Headline numbers in the **status bar**; click to profile again.
- **Spectra: Verify against baseline** re-profiles the same way and compares, beyond run-to-run noise.
- **Spectra: Run golden paths** and **Spectra: Open dashboard** (in VS Code's Simple Browser).
- Results that the CLI or an AI assistant writes to `.spectra/results` appear automatically.
- Offers Spectra's MCP server to agent mode (VS Code 1.101 or later).
